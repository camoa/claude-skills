# AIDA documentation

This is written stage by stage, as each part of AIDA is built. It covers the process and its
variants, not the internals of any one command — read a command's own description for that.

## Pages

| Page | Covers |
|---|---|
| [The project](project.md) | Finding, creating, and switching a project. What the check does when something is missing. Interactive versus autonomous behavior. Using your own guides, playbooks, and recipes instead of the hosted catalog. |

More pages arrive as more of AIDA is built:

- a task and its stages
- the five stages themselves
- the two build paths
- the two optional test harnesses

## Where to start

If you have never used AIDA, start with [The project](project.md). Every task lives inside a
project, so a project is the first thing AIDA needs from you.

# The surfaces at review

Review runs the end to end and visual regression harnesses when the project has them on, and you
walk every surface. Three checks record the result: end to end, visual regression and visual
parity.

## Where each part is

- **Set a harness up**, or answer the offer review makes when a kind is off:
  [set up surfaces](../../sources/surfaces-setup.md) and [surfaces](../../sources/surfaces.md).
- **Which surfaces run, your walk, a new baseline, and a light task:**
  [surfaces at review](../../sources/surfaces-at-review.md).

A command surface needs no walk, because its exit status is the whole answer.

## Why it works this way

- A passing surface can still look wrong, so you walk all of them, not only the ones that failed.

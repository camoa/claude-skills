# Scope

Scope is the first stage. It writes the task's contract: the goal, the expected result, the
acceptance criteria and the non-goals. You approve the contract before research starts, and every
later stage is judged against it.

Type `/aida:scope <task-id>`, or `/aida:scope` alone when one task is already active. A project
must be active, and the task must already exist. Scope creates neither. See
[the project pages](../../project/) and [the task pages](../../task/).

Scope does not research, design or build, and it runs no test. AIDA can check that later work
matches the contract. It cannot check that the contract is right. So this conversation is the one
place where the goal itself gets tested.

# The stages

Every task runs six stages, in this order. Each stage refuses to start until the one before it
has closed.

1. [Scope](scope/README.md): write the contract, the goal, the criteria and the non-goals you approve.
2. [Research](research/README.md): find what design needs, in your code, outside it, and in the recipes.
3. [Design](design/README.md): write the work orders and check them against the contract.
4. [Implement](implement/README.md): build each work order, tests first, and review it.
5. [Review](review/README.md): check the whole task against its contract and its code, for one verdict.
6. [Completion](completion/README.md): close the finished task and write its pull request body.

# Research

Research is the second stage. It finds out what is already true before anyone designs: what this
project already has, what exists outside it, which guides and recipes cover the work, and which
assumptions still hold. Design then acts on the findings and does not have to look again.

Type `/aida:research <task-id>`, or `/aida:research` alone when one task is already active. The
task needs a scope contract first. See [Scope](../scope/).

Research does not decide. It reports what exists and what is true of it, and design chooses.
Research does not read to the bottom of a subject either. It is done when every criterion has a
finding and every finding cites a criterion.
